## Featured Analytics Work

### 1. QuickBite Express — Crisis Recovery Analytics
**Python | MySQL | SQL | Data Validation | KPI Analysis**

End-to-end analysis of eight relational datasets covering customers, restaurants, orders, order items, delivery performance, and ratings.

- Orders changed from **110,672 to 33,441 (-69.78%)**
- Order value changed from **₹37.62M to ₹10.94M (-70.92%)**
- Active customers declined **63.56%**
- Average delivery time increased from **39.53 to 60.11 minutes**
- Built grain checks, key-integrity checks, reconciliation logic, SQL analytical views, KPI analysis, and recovery priorities

[View flagship case study →](https://github.com/codernav01/QuickBite-Crisis-Recovery-Analytics)
